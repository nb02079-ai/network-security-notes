## 1. SOC (Security Operation Center, 보안관제센터)
보안 이벤트를 모니터링·탐지·대응하는 조직/시설. 핵심 솔루션 계층:

| 약어 | 풀이 | 역할 |
|---|---|---|
| **SIEM** | Security Information & Event Management | 여러 장비·서버의 **로그를 수집·상관분석**해 이벤트 탐지 |
| **XDR** | Extended Detection & Response | 엔드포인트·네트워크·클라우드 등 **여러 영역을 통합 탐지·대응** |
| **SOAR** | Security Orchestration, Automation & Response | 대응 절차를 **자동화(플레이북)** 해 반복 작업을 처리 |
| **AI 기반 자율 SOC** | — | 위 기능에 AI를 결합해 탐지·대응을 자동화·지능화 |

- 흐름 이해: **SIEM(모아서 본다) → XDR(넓게 묶어 본다) → SOAR(자동으로 대응한다)**.

## 2. Wazuh
- 오픈소스 **SIEM + HIDS** 플랫폼. 에이전트를 각 호스트에 설치해 로그·파일 무결성·취약점을 수집하고, 중앙 대시보드에서 관제.
- 이후 실습에서 직접 구축하는 "미니 SIEM"의 참고 모델.

## 3. 보충 — 각 계층을 언제 쓰나
- **SIEM**: "무슨 일이 있었나"를 로그로 추적·분석(탐지·조사 중심).
- **XDR**: 엔드포인트~네트워크~클라우드에 걸친 공격을 하나의 맥락으로 연결.
- **SOAR**: 탐지 이후 "티켓 생성 → 격리 → 차단" 같은 반복 대응을 자동 실행.
- 셋은 경쟁이 아니라 **보완 관계** — SIEM이 탐지의 기반, SOAR가 대응의 자동화.
