> ⚠️ 아래 hping3 실습은 **격리된 실습망(자신의 VM 대상)** 에서 공격 탐지·방어를 배우기 위한 기록이다. 외부/타인 시스템 대상 사용 금지.

## 1. IDS / IPS
| 약어 | 풀이 | 역할 |
|---|---|---|
| **IDS** | Intrusion Detection System | 침입 **탐지** 시스템 — 공격을 감지·경고(탐지만) |
| **IPS** | Intrusion Prevention System | 침입 **방지** 시스템 — 감지 + 차단(인라인으로 막음) |

### 설치 위치 기준
| 구분 | 설명 |
|---|---|
| **NIDS / NIPS** | Network 기반 — 네트워크 구간을 지나는 트래픽을 감시 |
| **HIDS / HIPS** | Host 기반 — 개별 호스트(서버) 내부에서 감시 |

## 2. DDoS (Distributed Denial of Service)
- **분산 서비스 거부 공격**: 다수의 출발지에서 대상에 트래픽을 퍼부어 자원을 고갈시켜 정상 서비스를 막는 공격.
- 단일 출발지면 DoS, 분산되면 DDoS.

## 3. hping3 — 패킷 생성 도구 (Kali에서 실습)
환경: 공격자 Kali `192.168.16.14`, 대상 Ubuntu `192.168.16.127`.

```bash
# SYN 플러딩 (TCP SYN 대량 전송)
sudo hping3 192.168.16.127 -S -c 1000
   # -S: SYN 플래그, -c 1000: 1000개 전송

# 특정 포트로 전송
sudo hping3 192.168.16.127 -a 10.10.20.30
   # -a: 출발지 IP 위조(스푸핑) → 10.10.20.30이 보낸 것처럼 위장

# 출발지 랜덤 + 대량 + 데이터 크기
sudo hping3 192.168.16.127 --rand-source -c 1000 -d 10000
   # --rand-source: 출발지를 매번 랜덤으로 (추적 회피)
   # -c 1000: 1000개, -d 10000: 데이터 크기 10000바이트
```
- `-d`로 **MTU(보통 1500바이트)보다 큰** 데이터를 보내면 **fragment(분할)** 되어 전송된다.
- `-a` 스푸핑은 출발지를 속여 탐지·차단을 어렵게 만드는 전형적 수법 → IDS/방화벽이 이런 패턴을 탐지.

## 4. 정정·보충
- SYN 플러딩 방어: SYN cookie, 연결 수 제한(rate limit), 방화벽/IPS의 임계치 기반 차단.
- 출발지 스푸핑 대응: 경계 라우터에서 **uRPF**(Reverse Path Forwarding), 사설/비정상 출발지 필터링(BCP38).
- hping3의 `--flood`는 응답을 기다리지 않고 최대 속도로 보내는 옵션(더 공격적) — 실습 시 자기 망에만.
